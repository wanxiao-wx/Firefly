# 页面文字主题适配设计

## 背景

网页导航页使用了 `--text-90`、`--text-50` 等 CSS 变量，但这些变量目前没有全局定义。浏览器会忽略对应的无效 `color` 声明，导致文字继承结果与文章页的日间/夜间文字规则不一致。项目、时间线、日记和东信视频页面也复用了相同变量，因此存在同类问题。

## 目标

- 导航页主要文字在浅色主题下显示为黑色系，在深色主题下显示为白色系。
- 文字层级与文章页保持一致：主要文字使用 90% 不透明度，次要文字使用 70% 或 50% 不透明度。
- 同时修复所有已使用这些全局变量的页面。
- 保留主题色按钮、图标和图片遮罩中的固定白色文字。

## 方案

在 `src/styles/variables.styl` 的浅色和深色主题变量块中补全以下语义化文字变量：

- `--text-90`
- `--text-75`
- `--text-70`
- `--text-50`
- `--text-30`
- `--text-25`

浅色主题分别使用对应透明度的黑色，深色主题分别使用对应透明度的白色。已有页面继续通过变量引用这些颜色，不进行逐页重复修改。

## 页面检查范围

- 网页导航
- 项目
- 时间线
- 日记
- 东信视频
- 文章页与其他使用 `text-black/... dark:text-white/...` 的页面作为对照

固定在主题色背景、图片遮罩、横幅或状态标签上的白色文字属于有意设计，不纳入替换范围。

## 验证

- 使用静态断言确认浅色和深色主题均定义了完整变量集合。
- 运行 `pnpm check`、`pnpm type-check` 和 `pnpm build`。
- 在本地站点切换浅色和深色主题，检查导航页及受影响页面的主要、次要文字。

# 导航栏霓虹品牌 Logo 替换设计

## 目标

使用 `/Users/wanxiao/Downloads/xiaoshiyi-anime-neon-logo-v2.png` 替换网页左上角现有的头像 Logo 与“舌甘舌甘一笑”文字。替换后，整张霓虹“潇拾壹”图片独占原品牌区域，并继续作为返回首页的链接。

## 素材处理

- 原始 PNG 尺寸为 `1919 × 820`，带透明通道。
- 自动裁掉四周透明留白；裁剪后的可见区域约为 `1558 × 524`，宽高比约 `2.97:1`。
- 将裁剪结果转换为适合导航栏使用的轻量 WebP 源资源。
- 资源放入 `src/assets/images/`，由 Astro 图片管线生成响应式格式和尺寸。
- 不改变 Logo 内部颜色、发光、装饰符号或文字比例。

## 导航栏结构

- 修改 `src/components/layout/Navbar.astro`，将现有“单独 Logo + 标题文字”的渲染替换为一张完整品牌图。
- 品牌图仍位于指向首页的 `<a>` 内，保留现有按压缩放反馈和圆角点击区域。
- 不再在品牌图之后渲染 `navbarTitle`，避免文字重复。
- 图片替代文字使用“潇拾壹”。
- 使用 eager/high-priority 加载，避免导航栏首屏品牌图延迟出现。

## 响应式尺寸

- 手机端可见高度约 `36px`，宽度按原比例自动计算。
- 桌面端可见高度约 `44px`，宽度按原比例自动计算。
- 图片使用 `max-width: 100%`、`object-fit: contain`，不得拉伸变形。
- 品牌区域允许收缩但不得覆盖搜索、主题、菜单等右侧按钮。
- 导航栏整体高度维持现有 `72px`，不增加页面顶部占位。

## 主题与可访问性

- 保留 PNG/WebP 透明背景，在浅色、深色和壁纸模式下使用同一素材。
- 不对图片应用主题变色、滤镜或额外文字阴影。
- 首页链接保留键盘访问、可见焦点和有效替代文字。

## 验证

- 运行素材尺寸与透明通道检查，确认裁剪后没有透明大边距。
- 运行 `pnpm check` 和 `pnpm build`。
- 在本地网站检查首页与文章页的导航栏。
- 检查浅色、深色主题。
- 检查约 `375px` 手机宽度和桌面宽度，确认品牌图不变形、不溢出、不挤压右侧按钮。
- 确认旧头像及“舌甘舌甘一笑”不再单独显示。
